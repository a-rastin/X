## Implementation (reuse-first, minimal diff; uncommitted)

Runtime code (only capacity/status behavior; all queue/lease/inference
logic reused untouched):

- `backend/src/x_insight/operations/status.py` (new): `collect_status()`
  admin-only snapshot — queue (queued/leased per class, oldest eligible
  age, oldest heartbeat age), provider (trailing-24h attempts/failures/
  `PROVIDER_AUTH`/retries over generation jobs), inference (repeated-by-
  import enforcement constants + trailing-24h local failures), disk
  (`shutil.disk_usage` over the backup staging dir; unreadable → null,
  never 500), backup (latest job id/status + last success), requests
  (process-local per-group counts/errors/avg latency), alerts
  (`QUEUE_AGE` > 300 s, `HEARTBEAT_STALE` > 120 s, `PROVIDER_AUTH_FAILURES`
  ≥ 2/24h, `DISK_USAGE` > 80%). SELECT-only; never mutates queue/clinical
  state; thresholds are module constants (tunable engineering settings).
  Includes `RequestMetricsMiddleware` (outermost ASGI gauge:
  save/search/poll/other classification, fixed group keys so memory stays
  bounded, records 500 when no response completes).
- `backend/src/x_insight/models/capacity.py` (new): `measure_model()`
  (validate → canonical-JSON request bytes → build effective artifact →
  genuine bounded exact inference with wall time + `RUSAGE_CHILDREN`
  peak-RSS delta; returns nodes/cells/request/output bytes/seconds/RSS
  plus posteriors proving the run) and `check_admission()` (pre-flight
  against the pipeline's enforced constants by import, never forked;
  reasons name the `inference_resource` diagnostic). Failures unwrapped:
  invalid CPTs raise `CptValidationError`, over-limit artifacts raise
  `InferenceError` — exactly what enforcement raises.
- `backend/src/x_insight/operations/load_probe.py` (new):
  `make test-load` entry point (`python -m
  x_insight.operations.load_probe`; defaults 50 patients / 4 workers / 5
  provider samples, `$LOAD_REPORT`). Ordinary phase always (register + one
  draft save each + searches/polls, client-measured `perf_counter`
  count/avg/p50/p95/max per op); provider phase only with an explicit
  executor (outcomes tallied per status so a no-work pass can never pose
  as a fast run; report states the stub stand-in + unmeasured live LLM).
- `backend/src/x_insight/operations/router.py`: one route —
  `GET /api/v1/ops/status` (admin-only read, same authorization shape as
  audit reads; 401 anonymous / 403 non-admin).
- `backend/src/x_insight/app.py`: one line — outermost
  `RequestMetricsMiddleware` so edge rejections (413/422) count too.
- `Makefile`: `test-load` target (env-overridable patients/workers/
  provider-samples/output; `.env` loaded, dev loop untouched).
- `deploy/README.md` §9 (new): provisional targets labeled assumptions,
  load command + scale-up form, status endpoint + Status page, four alerts
  with operator responses, admission limits with measured headroom.
- Web (`web/src/`): `features/admin/status/api.ts` (typed client +
