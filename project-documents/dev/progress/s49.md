  sign only with complete current proposal, acknowledged saves, exact
  per-question acceptance/result refs including unchanged originals.
- §2 reject absent/failed/partial/stale originals, pending/failed/stale/
  mismatched currents, forged manual plans, wrong author/admin, outdated
  encounter/plan/review revisions. Freshness rechecked INSIDE the locked
  transaction via S48d per-question hash (not batch hash). Server
  recomputes; client flags never grant.

  recommendations, plan edits, inputs/versions, attribution), slot release

  failures leave no partial state (single transaction, row locks).
- §4 signed immutability vs live demographics; any-physician addenda
  (server actor/time, append-only, idempotent); shared chart read without
  draft leaks.

  preserve, stranger/admin 403 no leak, idempotent replay/409.
- T1 §§1+3: unchanged originals accepted + plan → one snapshot (original/
  final `80/20`, plan text, inputs/versions, signer/time, 64-char hash),
  revision +1, slot freed (follow-up 201, old draft 404), replay identical,
  key-conflict 409, one row in chart.
- T1 §§1+3 adjusted: Q1 `60/40` recalculated (`0.66/0.34`), accepted as
  `calculation` vs Q2 `baseline`; snapshot keeps original `80/20` vs final
  `60/40` with sections.
- T1 §2: unknown batch 404; pending/partial null-proposal 409; mutated CPTs
  fail closed with no baseline →409; stale edit →409 `STALE_INPUTS` (Q2
  stays fresh, no snapshot); recalculating →409 `NO_SUCCESSFUL_RESULT`;
  swapped/forged IDs →409 `REFERENCE_MISMATCH`; stranger/admin 403 no
  leak; old encounter/plan/review →412; extra plan text →422; denials leave
  chart empty + draft readable, corrected sign still succeeds.
- T1 §4: post-sign draft/notes/plan reads-writes 404, adjust/accept 409,
  second sign 409; live `patients` UPDATE (setup) moves chart demographics
  while snapshot patient/CPTs/hash stay byte-identical; stranger addendum

  snapshot (`80`, plan) without the other draft's `SENTINEL-SECRET-123`;
  stranger draft/review reads stay 403 no leak.
