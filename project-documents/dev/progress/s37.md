Why this shape: gate true requires `CurrentTreatment` with a documented
current baseline encounter/window, completed PANSS baseline and follow-up per
the S08 definition, and adequate clozapine-trial context with all other
required inputs known; gate false is improvement documented (current baseline,
completed PANSS baseline and follow-up, adequate-trial context, no
unknown/missing/conflict among required inputs). Gate false is
`not_applicable` with no posterior claim, never a negative finding or a fake
negative review posterior; unknown/missing/conflict — including outdated or
missing baseline, missing PANSS follow-up, and `not_assessed` severity —
pauses as `needs_clarification` rather than coercing to a known value and is
never coerced to improvement or to no improvement. No percent-change cutoff,
denominator or zero case is set; a missing PANSS follow-up is never treated
as no improvement. An outdated baseline pauses for a fresh baseline choice
with no recency threshold set. `not_assessed` severity pauses and never
coerces to `No`, with no invented score bands. `UrgentSafetyConcern Present`
renders a parallel urgent banner from saved structured inputs independently
of estimation latency — never a computed risk percentage. This F5 follow-up
package keeps a distinct network identity
(`BN_07_No_Improvement_Clozapine_Review_F5_v1`, workflow `followup`,
`s37-v1`) from the separate R7 `established_case_clozapine` registration
package even though BN-07 concepts overlap (different question_key, workflow,
gate, prompt and template). No dose, route, frequency or active/stopped
fields are collected or accepted; the prompt states the exclusion. Whether
review outputs behave as deterministic rules or estimated tables is an open
assumption recorded in the dossier; this draft uses estimated-table semantics
without approval, as are trial-adequacy/observation-window
operationalization, monitoring/willingness input meanings, severity without
bands, and recency without a threshold. The candidate 19-field history
(15 node-mapped CPT-context plus 4 gate-only baseline/PANSS applicability)
extends `history.v1` in isolation; runtime history, projections and readiness
remain unchanged.
