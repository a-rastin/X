## What `make test-recovery` does

Help text is `make test-recovery # recovery drill (pytest tests/recovery)`.
The recipe is `cd backend && uv run pytest tests/recovery`. Same shape as
the unscoped branch of `make test-backend`. It does not source `.env` and
does not create or drop a volume.

On this host `db-test` is published on port **5443** (`.env`
`TEST_DB_PORT`), database `x_insight_test`. A bare run without
`TEST_DATABASE_URL` would use `localhost:5433`, which was not listening.
The runs below exported `TEST_DATABASE_URL`.
