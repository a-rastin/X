## Scope (§§1-4)

- §1 only admin confirmation of the exact validated staged digest starts
  replacement; stale/mismatched confirmation fails 409 with re-validate
  guidance and no mutation. Quiesce writes/workers, fence deployment
  generation, take pre-restore backup before switching.
- §2 phased database-selection switch + coordinated process restart
  behind maintenance (`MaintenanceMiddleware` + `/ready` 503). No mixed
  old/new read/write traffic; old provider work cannot commit.
- §3 restore revokes sessions/grants, fences old workers, clears caches.
  Reconcile pending jobs against exact revision/lifecycle before eligible
  resumption; preserve failed unsolved CPTs and earlier successful
  results for local retry/reset (failed-unsolved-CPT rides the S47 path —
  documented partial, see code-review follow-up). Audit recovery
  externally and in the restored database (operator log), then verify
  login/read/replay before reopening.
- §4 inject failures before switch, during restart, at health check.
  Rollback restores the prior database/configuration and readable
  records; maintenance remains until verified healthy. UI exposes Held
  banner + reopen + recovery notes.

Depends DONE: S55 (isolated staging + immutable digest + expiry +
`restore_jobs`), S47 (failure confinement/bounded retry path reused for
failed-unsolved-CPT), S52 (admin-only audit view). NOT modified:

  id, generation bump, session-revoked + re-login +

  pending jobs reconciled against exact revision/lifecycle; failed

  externally and in restored DB; login/read/replay verified before
  reopen.

  DB/config with readable records and maintenance held; Held banner +
  reopen + `RESTORE_COMMIT_FAILED` + pre-restore id panel, then API
  reopen 200 clears it (`/ready` 200). Physician guard (no nav + guarded
  route hides all S56 hooks + API 403/401 for validate/get/commit/
  reopen), dark theme + keyboard.

  drill + UI confirmation/progress + operator recovery procedure — green
