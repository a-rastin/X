## What works

- Two physicians remain isolated while a provider attempt fails or is held.
  The final deterministic proof holds A until B's save, adjust, local
  recalculation, and acceptance are acknowledged, then checks A is still
  leased with no baseline before release. Durable state survives fresh API
  instances/engines/logins and a real worker subprocess reread.
- Mixed bounded exhaustion resumes at the failed stage without losing completed
  artifacts. Lease theft/crash, archive-before-claim and in-flight archive,
  deployment-generation fencing, and reclaim-once preserve unique artifacts.
- Real provider/MCP exchanges exclude notes, unrelated fields, identifiers,
  and secrets. Final tool probes seed sentinels on the same encounters being
  exercised and scan every outbound exchange, echoed tool result, and stored
  response; the exact per-job grant value is checked, not merely its key.
  Forgery, role/author, CSRF, revision, XML and destination denials are observable
  without unintended mutation. Existing suites cover archive traversal and
  scoped-grant isolation.
- Signing requires exact current acceptance; stale/reset/manual denials,
  re-acceptance, atomic/idempotent signing, escaped reports, and export
  permissions are covered at backend seams.
- Browser checks cover wrong-author presentation, saved draft recovery,
  failed/stale states, client signing preflight, and literal markup rendering.
