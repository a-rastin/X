## Scope and synthetic basis

- §1 admin-only patient/physician CSV with stable English
  headers, UTF-8, `QUOTE_MINIMAL` quoting, and no credentials.
  Patient identifier `0012345678` stays exact 10-digit text bytes
  (never a numeric column, never a `="..."` wrapper).
  Physicians are denied list exports (403).
- §2 formula-like user text neutralized with a leading `'`
  (no formula wrappers anywhere); quotes/newlines round-trip
  through standard CSV quoting. The import-as-Text note is
  operator documentation (Exports page copy); over HTTP the
  suite proves the raw bytes stay exact text.
- §3 admin-only escaped signed-patient HTML with chronology,
  frozen clinical content, secondary plans, signatures, and
  addenda (physicians 403 per the provisional print policy,
  plan §§1.3, 2.1). Every question carries complete original +
  accepted CPTs/results/recommendations, pinned/network/template
  versions, adjustment indicators (unchanged / adjusted /
  adjusted-then-reset with retained history), and
  physician/timestamps. Adjusted-then-reset keeps an explicit
  history indication while reporting final-equality separately.
  Reports exclude private drafts by construction.
- §4 readable browser print view with page breaks and research
  labeling in both browsers; authenticated responses are
  `private, no-store`. No PDF library, no dynamic LLM report
  prose — sections come from stored baselines/results/templates
  only.

Depends DONE: S06 (directory/demographics), S20 (medications/DDI

Synthetic scope explicit: real admin/physician sessions and real
