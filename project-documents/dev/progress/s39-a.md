## Root cause and correction

The S39 inventory recorded the first five `wrong_dimensions` diagnostics.
The full public `check_semantics` report actually contains 21: every reference
TABLE repeats its rows by an extra factor equal to the child cardinality.
Binary roots therefore contain four values instead of two; the three-state
root contains nine instead of three. Child tables have the same defect.
The prior S38 suite checked complete estimated CPT fixtures rather than
semantic validity of the actual reference XML, so the malformed reference
TABLEs could coexist with passing inference tests.

The correction preserves each synthetic row and repeats it exactly once per
ordered parent-state combination. All 21 variables, states, ordered GIVENs,
clinical wording, gates, source hashes, candidate history and numerical
examples are retained. The network identity, model, prompt and template
versions advance to `s38-v2` / `BN_06_Continue_Or_Adjust_Review_F6_v2`.
The new review dossier records the predecessor hashes and correction;
synthetic reference probabilities remain mathematical fixtures without a
clinical probability claim. This is a correction, not a new clinical design
decision; rationale remains in the existing dossier and this report.
