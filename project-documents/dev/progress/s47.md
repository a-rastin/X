# S47 — Bound failures and recover at exact failed stage (2026-10-09)

Bound mixed failures to one shared budget (initial + two retries, three
total) with backoff/Retry-After cap and persisted next eligibility, then
resume at the exact failed stage reusing persisted artifacts: inference
reuses accepted CPTs, rendering reuses the stored result, successful
earlier questions make no new provider requests. Crash/restart and
lease-reclaim fencing preserve attempt counters and unique commits; stale
edits, discard/archive/deactivation, and configuration replacement fence
late commits. No nested adapter retries; no guessed clarification values.
Synthetic A→B networks from plan.md §7.4 yield empty-evidence
`P(A=yes)=0.20`, `P(B=yes)=0.22` per question. Backend implementation
(dev-backend) + durable tests (dev-test) are done, uncommitted. No
clinical release package required; S39 bundles + S24 registry supply
pinned packages later.

## What works

- Timeout, transient 5xx/429, transient MCP failure, and invalid CPT
  share one budget (initial + two retries); retry delay is exponential
  with bounded jitter/Retry-After capped at 60s with persisted
  `next_eligible_at`; attempt start is persisted before outbound work;
  bad credential/model/capability fails configuration immediately with a
  new pinned run on settings repair.
- Exhausted budgets leave a clear failed-question message with later
  questions pending and drafts plus completed sections retained;
  required missing/conflicting input or unknown gates yield
  needs-clarification with no guessed values or blind retries.
- Manual author-only retry at matching run revision with unchanged inputs
  starts a new bounded batch at the failed stage with prior history
  retained; inference resumes without re-estimating and rendering
  resumes without provider/inference.
- Crash/restart resumes from persisted artifacts/attempt counters after
  lease recovery; lease loss fences the old worker even if its provider
  call finishes; only committed application artifacts are idempotent.
