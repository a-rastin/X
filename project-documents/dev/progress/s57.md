## Drill findings (defects found and fixed in-slice)

- F1 backup staging unwritable: `prod_recovery` mounts root-owned, app runs
  as UID 10001 → `BACKUP_EXPORT_FAILED EACCES`. Fixed in `Dockerfile.app`
  (pre-create + chown recovery dirs; named volumes inherit image ownership
  on first mount). Backup then succeeded live (`succeeded`, 3994 B drill
  archive, sha recorded).
- F2 `Secure` cookie missing behind TLS: uvicorn 0.54 `--proxy-headers`
  trusts only `FORWARDED_ALLOW_IPS` (default loopback), and the edge reaches
  app from a bridge IP → forwarded proto ignored. Fixed with
  `FORWARDED_ALLOW_IPS: "*"` on app, safe because app publishes no host
  ports (edge is its sole upstream); `Secure` then proven live over TLS,
  correctly absent on loopback HTTP.
