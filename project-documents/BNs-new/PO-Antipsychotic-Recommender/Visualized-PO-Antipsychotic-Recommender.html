Root priors

Each factor is an independent binary root with a user-specified marginal prior (dated 2026-11-05). Every table lists P(No) then P(Yes), and each pair sums to 1.

Most probable complete profiles

Prior joint probability of each complete No/Yes profile, from the product of the 16 independent root priors. The last column shows the CPT's leading medication for that profile.

Prior joint probability checks

Computed in your browser from the 16 root tables.

Medication weight matrix

The weight each medication receives when a factor is Yes. A No contributes 1 to every medication. A weight of 0 removes the medication entirely for any profile that includes that factor.
