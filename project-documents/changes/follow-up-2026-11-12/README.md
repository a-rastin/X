source-confirmation or medical-approval prerequisite on development; the
[research development policy](../../dev/follow-up-specification.md#research-development-policy)

the attachments; the flowchart governs antipsychotic decisions and the Word
document governs forms and other recommendations. The original LAI node is a
dead end, handled by the confirmed physician-review outcome. New side-effect
rules extend the graph as specified; do not infer missing clinical algorithms.

in step 7 are stale numbering. Use the named fields and seven-step ordering in
the specification. Its reference to another oral-network document has no embedded
hyperlink; fixed-model reuse was separately confirmed.
